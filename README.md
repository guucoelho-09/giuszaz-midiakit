# Mídia kit Giuszaz 2027

Site de uma página, sem build. O conteúdo fica em `content/site.json` e é editado pelo painel em `/admin`.

- `index.html` estrutura e estilo
- `app.js` monta a página a partir do conteúdo
- `content/site.json` textos, números, links, fotos e vídeos
- `admin/` painel de edição (Decap CMS + Netlify Identity)
- `img/` e `video/` arquivos de mídia
